# Drill 14 개발 문서

## 개요

`drill_14.py`는 LEC16의 소년, 잔디, 게임 월드를 바탕으로 `bird_animation.png`의 새 10마리가 소년 머리 위를 좌우로 왕복 비행하는 Pico2D 애니메이션이다. 새들은 두 줄로 배치되어 무리를 이루며 함께 비행한다. 방향키로 소년을 움직이고 Space로 공을 던질 수 있으며, `Esc`로 종료한다. 실행할 때 이 폴더를 현재 작업 디렉터리로 지정한다.

```powershell
python drill_14.py
```

## 시간 기반 이동

이동 속도는 `FLIGHT_SPEED_PPS`에 초당 픽셀 수(PPS)로 지정한다. 매 프레임의 시작 시각을 `time.perf_counter()`로 기록하고, 현재 프레임과 이전 프레임의 시각 차이를 경과 시간으로 계산한다.

```text
frame_time = current_time - previous_time
distance = speed_pps * frame_time
```

새 떼의 위치는 이 거리만큼 갱신한다. 따라서 프레임 속도가 달라져도 시간당 이동 거리는 일정하다. 새 떼는 소년 머리 위에서 출발해 화면 좌우 경계 사이를 비행하며, 경계에 닿으면 방향을 반전한다. 큰 프레임 간격에도 경계에서 남은 이동 거리가 보존된다.

## 날개짓 프레임

스프라이트 시트는 5열, 3행으로 나뉘며 마지막 칸은 비어 있어 실제 애니메이션 프레임은 14개다. 열 프레임마다 `ANIMATION_FPS`에 프레임 경과 시간을 곱해 프레임 위치를 진행시키고, 전체 프레임 수로 나머지를 계산해 반복한다. 새마다 시작 프레임을 다르게 설정해 날갯짓을 분산한다.

## 조정 가능한 값

| 상수 | 설명 |
|---|---|
| `FLIGHT_SPEED_PPS` | 수평 비행 속도(픽셀/초) |
| `ANIMATION_FPS` | 날개짓 애니메이션 프레임 진행 속도 |
| `BIRD_WIDTH`, `BIRD_HEIGHT` | 화면에 그릴 새 한 마리의 크기 |
| `BIRD_OFFSETS` | 새 떼 내 각 새의 상대 위치 |
| `CANVAS_WIDTH`, `CANVAS_HEIGHT` | 게임 화면 크기 |

## LEC16 연동

소년과 잔디는 `Boy`, `Grass`, `game_world`를 사용해 LEC16과 같은 방식으로 업데이트하고 그린다. `game_framework.frame_time`에 현재 프레임 경과 시간을 전달해 소년의 달리기 애니메이션과 공의 이동도 시간 기반으로 유지한다. 새 떼는 소년보다 높은 화면 좌표에 배치하고 월드 위에 그려 항상 머리 위 하늘을 비행한다.
