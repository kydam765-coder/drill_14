# Drill 14 개발 문서

## 개요

`drill_14.py`는 `bird_animation.png`의 날개짓 프레임을 사용해 네 마리 새가 무리를 이루어 좌우로 비행하는 Pico2D 애니메이션이다.

## 실행

이 폴더를 현재 작업 디렉터리로 지정하고 다음 명령을 실행한다.

```powershell
python drill_14.py
```

`Esc` 또는 창 닫기 이벤트로 종료한다.

## 시간 기반 이동

`FLIGHT_SPEED_PPS`는 초당 이동 픽셀 수(PPS)로 속도를 정의한다. `time.perf_counter()`로 현재 프레임과 직전 프레임의 시각 차이를 구하고, 그 값을 속도에 곱해 이동 거리를 계산한다.

```text
frame_time = current_time - previous_time
distance = speed_pps * frame_time
```

이 방식은 프레임 속도가 달라져도 초당 이동 거리를 일정하게 유지한다.

## 날개짓 프레임

스프라이트 시트는 5열, 3행이며 마지막 칸은 비어 있어 애니메이션 프레임은 14개다. 새는 `ANIMATION_FPS * frame_time`만큼 프레임 위치를 진행시키고, 전체 프레임 수로 나머지를 계산해 반복 재생한다. 새마다 시작 프레임을 다르게 설정해 날갯짓을 분산한다.

## 조정 가능한 값

| 상수 | 설명 |
|---|---|
| `FLIGHT_SPEED_PPS` | 수평 비행 속도(픽셀/초) |
| `ANIMATION_FPS` | 날개짓 프레임 진행 속도 |
| `BIRD_WIDTH`, `BIRD_HEIGHT` | 새 한 마리의 화면 표시 크기 |
| `BIRD_OFFSETS` | 무리 내 각 새의 상대 위치 |
| `CANVAS_WIDTH`, `CANVAS_HEIGHT` | 화면 크기 |

새 떼의 전체 너비를 고려해 좌우 이동 범위를 정한다. 화면 끝에 도달하면 진행 방향을 바꾸며, 왕복 좌표는 반사 주기 계산을 사용해 프레임 간격이 커도 경계에서 남은 이동 거리를 보존한다. 반대 방향으로 비행할 때는 스프라이트를 좌우 반전한다.

## 확인 항목

- 1초 동안 이동한 거리가 `FLIGHT_SPEED_PPS`와 일치하는지 확인한다.
- 날개짓 프레임이 14개를 순환하고, 네 마리의 시작 프레임이 다른지 확인한다.
- 좌우 끝에서 새 떼가 화면을 벗어나지 않고 방향을 바꾸는지 확인한다.
- 프레임 간격을 늘려도 이동이 경계에서 멈추거나 순간 이동하지 않는지 확인한다.
