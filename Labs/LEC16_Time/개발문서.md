# Drill 14 개발 문서

## 개요

`drill_14.py`는 `bird_animation.png`의 날개짓 프레임을 사용해 네 마리 새가 무리를 이루어 좌우로 비행하는 Pico2D 애니메이션이다.

## 실행

이 폴더를 현재 작업 디렉터리로 지정하고 다음 명령을 실행한다.

```powershell
python drill_14.py
```

`Esc` 또는 창 닫기 이벤트로 종료한다.

## 시간 기반 이동

`FLIGHT_SPEED_PPS`는 초당 이동 픽셀 수(PPS)로 속도를 정의한다. `time.perf_counter()`로 현재 프레임과 직전 프레임의 시각 차이를 구하고, 그 값을 속도에 곱해 이동 거리를 계산한다.

```text
frame_time = current_time - previous_time
distance = speed_pps * frame_time
```

이 방식은 프레임 속도가 달라져도 초당 이동 거리를 일정하게 유지한다.
